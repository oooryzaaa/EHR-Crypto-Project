# Taste

## Documentation

- For code-explanation docs, prefers a line-by-line walkthrough format (explaining the code and *why* each choice was made) over summary/table-of-contents style documents. Confidence: 0.6
- Wants cheatsheet/reference docs turned into a ready-to-read presentation script: spoken narration plus marked (non-spoken) actions, ordered web explanation first, then code walkthrough. Confidence: 0.55
- Documentation wanted for study purposes should be delivered as plain `.md` files in `docs/`, not as new web pages/features embedded in the app. Confidence: 0.5
